# Static reference fallback

Use only when the actual project preview cannot run or be displayed. Label it **static reference — actual component rendering unverified**, explain the missing prerequisite, and keep the live-preview requirement open. It is not equivalent to the executable layout requested by this skill.

Save one self-contained HTML per meaningful screen/state under `screens/`, with an index when useful. Source styling from the selected project implementation; identify substitutions. Preserve stable visible anchors and matching `data-anchor` attributes. Include representative long content and documented error states; keep unknown behavior labeled as proposed or unresolved.

Apply [feedback.md](feedback.md) unchanged. Store original reviewer words, replies, status, evidence and history in `feedback-ledger.json`; an optional human-readable `feedback.md` may show pending, needs-clarification and handled items. Neither a checked box, silence, nor clearing/removing a note approves the design. Capture whole-version confirmation independently, with its limited/static scope stated explicitly.
